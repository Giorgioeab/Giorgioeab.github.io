# Informações do Projeto para Portfólio

Aqui estão as opções de texto formatadas para uso em portfólio, destacando a atuação Fullstack.

## Opção 1 (Focada em Fullstack & Integração)

**Título:**
Espanhol Essência - Lead System

**Descrição:**
Neste projeto, desenvolvi uma solução completa de captação de leads. No frontend, **usei TypeScript** para criar um sistema de validação robusto que verifica WhatsApp e e-mails em tempo real, garantindo dados limpos antes mesmo do envio. No backend, **implementei uma API em PHP** integrada a um banco de dados **MySQL**, onde criei a arquitetura das tabelas para armazenar e organizar os inscritos com segurança.

**Tecnologias:**
`TypeScript` `PHP` `MySQL` `Tailwind CSS` `Vite`

---

## Opção 2 (Focada em Engenharia de Software)

**Título:**
Conecta en Español & Lead Capture

**Descrição:**
Construí esta *landing page* com foco em performance e integridade de dados. **Utilizei TypeScript** para toda a lógica de interação e controle de formulários, eliminando erros comuns de input do usuário. Para a persistência dos dados, **configurei um ambiente PHP com PDO** e **MySQL**, implementando queries seguras (Prepared Statements) para prevenir SQL Injection e garantir a segurança das informações dos usuários.

**Tecnologias:**
`Fullstack` `TypeScript` `PHP/MySQL` `Cybersecurity`

---
